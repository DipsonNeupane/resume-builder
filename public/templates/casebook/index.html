Template structure

Structure
Editorial header that gives the portfolio link primary weight. Summary set as a statement. Project/"Selected work" sections become a two-up grid of numbered case-study cards (title, role/client, detail, link). Experience condensed after the work; capabilities in columns.
Section order
Statement → Selected work → Experience → Capabilities → Education → Other
Typography
Instrument Serif display for name, statement and case titles; Instrument Sans for text.
