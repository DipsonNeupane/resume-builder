How this design is organized

Structure
Grouped stack matrix directly under the header. Project sections promoted above experience. "Stack:" and "Link:" detail lines lifted into a monospaced metadata line per entry; URLs become short clickable links.
Section order
Summary → Stack → Projects → Experience → Education → Certifications → Other
Typography
IBM Plex Sans for text; IBM Plex Mono for headings, dates, stacks and links.
Distinct from other designs
All seven put skills last as one comma paragraph and treat projects as a generic section. Stackline makes the stack and shipped work the first read.
