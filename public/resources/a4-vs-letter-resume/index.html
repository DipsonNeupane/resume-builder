A4 vs. Letter: choosing a resume page size

The page sizes are close, but changing between them can move lines and page breaks.

On this page
  1. Know the physical difference
  2. Follow the actual request
  3. Recheck after every size change
  4. Keep page size separate from file format
  5. Verify the local convention

Short answer

Follow the request, then check the exported pages.

Use the size explicitly requested by the employer or application system. If no size is specified, use the convention you can verify for that application context. Always inspect the final PDF or Word file after switching: A4 is narrower and taller than US Letter, so a stable draft can repaginate.

1. Know the physical difference

A4

210 × 297 millimetres

US Letter

8.5 × 11 inches (215.9 × 279.4 millimetres)

The difference is large enough to affect wrapping and page breaks even when the type and margins stay the same.

2. Follow the actual request

A country-level convention is only a default. A multinational employer, university, government portal or recruiter may specify a different page size or file format. The job posting and upload instructions are stronger evidence than a generic list.

3. Recheck after every size change

  • No heading is stranded at the bottom of a page
  • Dates and contact details have not wrapped awkwardly
  • Bullets are not clipped or split confusingly
  • Page count still suits the amount of relevant evidence
  • The downloaded file matches the preview

4. Keep page size separate from file format

A4 versus Letter describes the page dimensions. PDF versus Word describes the file. An employer may request any combination. APWICO supports both page sizes in its templates and provides server-generated PDF and Word exports under the current access policy.

5. Verify the local convention

Paper size varies within countries and organizations. Use the regional verification method, then let the vacancy and upload instructions control.
