# PDF font assets

Source: Google Fonts, official google/fonts repository, fetched September 19, 2026.
- ofl/notosansarabic/NotoSansArabic[wdth,wght].ttf
- ofl/notosansdevanagari/NotoSansDevanagari[wdth,wght].ttf

Both distributed under SIL Open Font License; accompanying OFL files retained.
Regular static instances (wght=400, wdth=100) generated with fontTools for PDF interoperability testing. No customer content is sent to font services. Latin/Cyrillic/Greek and Chinese assets are loaded from installed @fontsource packages, embedded as data fonts. Extraction acceptance remains documented in HANDOFF.md; font coverage is not a claim that every script has passed output tests.
